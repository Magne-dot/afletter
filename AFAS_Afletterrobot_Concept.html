AFAS Afletterrobot

Concept voor automatische verwerking van betaalspecificaties.

  1. Openstaande posten ophalen via AFAS GetConnector.
  2. PDF, Excel of e-mail uitlezen.
  3. Factuurnummers herkennen.
  4. Matchen tegen openstaande posten.
  5. Afletteren via AFAS API.

Datastroom

Specificatie -> Parser -> Factuurnummers -> Matching -> AFAS API -> Aflettering
